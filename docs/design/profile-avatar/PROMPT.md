# Задача: внедрить новый экран «Perfil» и редактор аватара в Android-приложение GuaraniMath

Ты работаешь в репозитории GuaraniMath (Android, Kotlin, Jetpack Compose, модуль `app/`). Нужно перенести в приложение готовый дизайн двух экранов:

1. новый экран профиля;
2. новый экран-редактор аватара с системой открываемых вещей.

**Главное правило: визуал не меняешь.** Дизайн утверждён. Твоя работа — сделать так, чтобы он работал в реальном приложении и выглядел на устройстве так же, как на эталонных скриншотах. Нельзя:
- «улучшать», упрощать или менять цвета, отступы, скругления, шрифты, размеры, тени, иконки, порядок блоков и тексты;
- подставлять стандартные Material-компоненты с их собственным видом (Material `NavigationBar`, `Card` с elevation, `LinearProgressIndicator` и т. п.), если они не совпадают с макетом пиксель в пиксель. Рисуй свои composable по макету.

Если что-то невозможно повторить 1:1, не придумывай замену молча. Сделай максимально близко и перечисли расхождения в итоговом отчёте.

Перед работой прочитай `AGENTS.md` и `specs/protocols/BOOT.md` и следуй им: быстрый цикл визуальных правок, не трогать прогресс пользователя, проверка через `:app:assembleDebug` и `adb install -r`.

## 4. Общие приёмы

- **«3D-край»** карточек, кнопок и кружков в макете — это НЕ размытая тень. Это сплошная тень со смещением: `box-shadow: 0 Ypx 0 <цвет>`. В Compose рисуй через `drawBehind`: сначала тот же скруглённый прямоугольник или круг цветом края, смещённый на Y вниз, потом сам элемент. Не используй `shadowElevation` для этих мест.
- Цвета текста: основной `#1d2b4f`, вторичный `#5d6a82`. Синий `#2d63d6` (край `#1f4ba8`), жёлтый `#f5c230` (край `#d69f12`), голубой `#58c0ec`, серые кружки `#eef1f5` (край `#c8cfd9`).

## 5. Аватар: `AvatarView(look: AvatarLook, size: Dp)`

- Один composable используется везде: профиль, меню, редактор, плитки, баннер.
- Портируй `spec/avatar-template.svg`: каждый `<path>/<circle>/<ellipse>/<rect>` — слой в том же порядке. Рисуй в `Canvas` с масштабом `size/200` через `PathParser().parsePathString(d).toPath()`; для примитивов — `drawCircle`/`drawOval`/`drawRoundRect`.
- Слои внутри `<sc-if value="{{флаг}}">` рисуются, только когда флаг из `headVals` true.
- `{{skinShade}}`, `{{hairHi}}` и т. п. вычисляются функцией `mix()` из `spec/avatar-vals.js`. Портируй её точно, включая коэффициенты 0.14 / 0.35 / 0.25 / 0.2.
- Учитывай `opacity`, `fill-opacity`, `stroke-width`, `stroke-linecap="round"`, `stroke-linejoin="round"`, `fill="none"`.
- Всё обрезай кругом (`clip(CircleShape)`).
- Звёзды (`starEyes`, `starLenses`) генерируются функцией `star()`, её тоже портируй.
- Критерий: `AvatarView` при одинаковом `look` визуально совпадает с аватаром на эталонных скриншотах.

## 6. Данные

```kotlin
data class AvatarLook(
    val skin: String = "#f4c29a", val hair: String = "#5a3a22", val hairStyle: String = "short",
    val expr: String = "smile", val hat: String = "cap", val glasses: String = "none",
    val outfit: String = "tee", val shirt: String = "#2d63d6", val bg: String = "#dfe8fb",
)
```

**Хранение.** Добавь `avatar: AvatarLook` в `ProgressSnapshot`. `encode`/`decode` — под ключом `"avatar"`.
- Если ключа нет (старые сохранения), берутся значения по умолчанию.
- **Существующий прогресс не должен сбрасываться.**
- Метод `ProgressRepository.saveAvatar(look)`.

**Правила открытия.** Положи `spec/unlock-rules.json` в `app/src/main/assets/avatar/unlock-rules.json` и читай оттуда. Условия:
- `free` — открыто всегда;
- `xp` — `progress.xp >= n`;
- `lessons` — `completedLessonIds.size >= n`;
- `topic` — все уроки из `topicLessonIds[topic]` пройдены. Пустой список означает «пока закрыто»; реальные id уроков по темам потом проставит автор курса;
- `stage` — пройдены все уроки курса.

**Безопасность надетых вещей.** Если в сохранённом `look` оказалась закрытая вещь (правила поменялись), показывай её, но в редакторе выбрать её снова нельзя.

**Тексты.** Все испанские строки из макета вынеси в одно место (ресурсы или объект-константы) **без перевода**: перевод на гуарани сделают отдельно. Имя пользователя и «@usuario» — плейсхолдеры в одном месте (в данных профиля имени пока нет).
