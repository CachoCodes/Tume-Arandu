# TECHDEBT-PROTOCOL

TECHDEBT хранит осознанный долгоживущий инженерный компромисс вне acceptance текущей работы. Если обязательный критерий не выполнен, задача остаётся незавершённой — запись долга не заменяет реализацию.
Идеи живут в backlog, временные блокеры — в BOARD/checkpoint, неясный канон — REVIEW.
Для изменения поведения обнови owning spec по SPEC-PROTOCOL; для отдельного прохода создай WI.

Один риск — одна запись `TD-NNN` в Open с полями: area, related (spec/WI), current state, risk, trigger, mitigation. Добавь owner, если он известен.
При планировании исправления свяжи запись с WI; после проверки результата перенеси в Resolved. Не дублируй один и тот же текст в WAL и реестре долга.
