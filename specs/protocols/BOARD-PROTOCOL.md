# BOARD-PROTOCOL

Одна строка = один `WI-NNN`; одна задача находится ровно в одной секции.
BOARD — единственный источник status, owner, priority и blocker. Scope, acceptance и результат находятся в файле WI.

Формат строки: ссылка WI | Owner | Priority | Blocker. Заголовок ссылки содержит ID и короткое название результата.
- Backlog: нужная работа, ещё не начата. Черновые критерии дополняются до реализации.
- In Progress: назначен owner и работа реально начата; WAL при старте не требуется.
- Blocked: внешнее условие останавливает работу; указаны причина и ожидаемое действие.
- Done: все AC проверены, Result содержит evidence, долг/REVIEW отражены, checkpoint удалён, ссылка ведёт в архив.
Сложность реализации сама по себе не Blocked. Недоступная обязательная проверка препятствует Done.

Перед изменением ownership прочитай `.me`; не переназначай чужую работу без поручения пользователя. Обновляй только строки своей работы.
При изменении статуса обновляй только BOARD; WAL меняется лишь при значимой остановке/передаче. ROADMAP остаётся опциональной картой зависимостей, без дублирования статусов.
Legacy FEAT/INFRA строки сохраняются до точечной миграции по `.human/adopt-existing-project-agent.md`.
