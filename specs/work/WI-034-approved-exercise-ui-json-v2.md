# WI-034: Единый JSON уроков и согласованный Android UI заданий

Canon action: new-spec

## Outcome

Новые уроки и упражнения задаются одним проверяемым JSON-форматом и отображаются в Android через согласованные общие компоненты семи визуальных вариантов без привязки оформления к ID.

## Scope

- In: контракт локализованного JSON v2, миграция встроенного курса без смены ID, проверка пакета, Compose-экран задания по согласованным браузерным прототипам, состояния ответа и объяснения, документация для авторов, сборка и проверка APK, PR.
- Out: сервер, AI-генерация контента, пользовательский импорт файла в приложении, смена Android стека и зависимостей, сброс прогресса.

## Specs

- Governing: планируемый `spec://modules/learning/PROP-011-course-json-format#root`.
- Governing: `spec://modules/learning/FEAT-010-learning-demo#exercises`.
- Constraint: `spec://modules/android/PROP-010-android-demo-architecture#course-schema`.

## Acceptance

- AC-1: один встроенный JSON v2 содержит обе локализации, сохраняет существующие ID и загружается в оба языка; ошибочный пакет отвергается с понятной ошибкой до показа.
- AC-2: все семь согласованных вариантов упражнения отображаются через данные типа/оформления, без проверок конкретного exercise или lesson ID в UI.
- AC-3: правильный и неправильный ответ показывают нижнюю плашку с объяснением и действием продолжения; неверные задания возвращаются позже в уроке без потери прогресса.
- AC-4: Android debug APK собирается, устанавливается и затронутые экраны проверены на эмуляторе, включая ближайшие состояния ошибки/успеха.
- AC-5: спецификации и руководство автора описывают один JSON-формат, границы проверки и способ добавления урока; spec-lint проходит.
- AC-6: изменения опубликованы в PR для `CachoCodes/Tume-Arandu`.

## Dependencies

Продолжает визуальные изменения WI-031 и WI-033 из локального рабочего каталога; их исходный код и канон нужно включить в PR.

## Risks

Перенос двух локализаций в один файл может изменить загрузку курса; проверить равенство ID и ответов до/после миграции. Прогресс пользователя не очищать и не подменять. UI не должен открывать помощь или засчитывать неверный ответ как правильный.
