# WI-031: Сопоставление двумя столбцами карточек

Canon action: direct-edit

## Outcome

Задания на сопоставление позволяют выбрать две соответствующие карточки из отдельных столбцов без выпадающих списков и лишнего треугольника.

## Scope

- In: общий matching UI для GN/ES, состояния выбора и проверки, отсутствие схемы 3–4–5 в matching и его помощи.
- Out: изменение содержания заданий, ключей ответов, остальных типов и прогресса.

## Specs

- Governing / affected: `spec://modules/learning/FEAT-010-learning-demo#exercises`, `spec://modules/learning/FEAT-010-learning-demo#lesson-content`.

## Acceptance

- AC-1: Обычное matching показывает два столбца крупных карточек; ученик выбирает левую и правую карточки, видит их связь без опоры только на цвет и может исправить выбор до проверки.
- AC-2: Существующая нижняя кнопка проверяет только полное сопоставление; неверный ответ можно исправить, верный продолжает урок. Угловое сопоставление сохраняет немедленную проверку пар.
- AC-3: Схема 3–4–5 отсутствует в карточке matching и его помощи; остальные задания на отношения сторон её сохраняют.
- AC-4: Сборка проходит; GN/ES, доступные названия действий и сохранённый прогресс работают.

## Dependencies

Текущий Compose `CourseApp.kt`, курс JSON и локальный эмулятор.

## Risks

Длинные подписи могут не уместиться в квадратах; карточки должны переносить текст и прокручиваться вместе с заданием.

## Result

Частично выполнено, 2026-09-25. Реализованы квадратные карточки в двух колонках, парные номера, уникальное назначение, закреплённый разбор `solutionViewed`, восстановление верных пар и исключение треугольника из matching/help. Build и экранная проверка прошли. Эмулятор содержал сохранённый `ratios-match` с `solutionViewed=true`, поэтому изменять пары и проверять нижнюю кнопку на этом read-only упражнении было нельзя; неправильную/верную отправку и немедленную проверку угловых пар не проходил. Данные приложения не очищались: APK обновлён командой `adb install -r`, сохранённый экран разбора восстановился. Каталог проекта не содержит Git metadata (`git status` отвечает `not a git repository`), поэтому commit и working-tree status недоступны.

REVIEW: перед архивированием нужен общий визуальный/интерактивный прогон root на незавершённом matching, включая исправление выбора, нижнюю проверку и немедленную проверку угловых пар.
