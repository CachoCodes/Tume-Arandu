# WI-022: Сопоставление и нижнее действие упражнения

Canon action: direct-edit

## Outcome

Экран сопоставления показывает градусы слева, названия соответствий справа и понятный рисунок угла; действие проверки постоянно находится в нижней панели и недоступно до заполнения ответа; кнопка помощи использует стандартную лампочку.

## Scope

- In: выстроить сопоставления в строки с градусами слева и отношением справа; добавить визуальный эскиз для соответствий углов; закрепить действие проверки для всех типов упражнений; отключать его до готовности ответа без сообщения об незаполненных парах; заменить самодельный символ помощи стандартной иконкой лампочки.
- Out: менять упражнения/ответы курса, теорию или карту курса, включая её 3D-модель.

## Specs

- Governing / affected: `spec://modules/learning/FEAT-010-learning-demo#lesson-content`, `spec://modules/learning/FEAT-010-learning-demo#exercises`, `spec://modules/learning/FEAT-010-learning-demo#solutions`.
- Constraint: `spec://modules/android/PROP-010-android-demo-architecture#implementation-map`.

## Acceptance

- AC-1: В упражнении сопоставления значение в градусах отображается слева, выбор соответствия — справа; для углов справа виден наглядный эскиз выбранного вида угла.
- AC-2: Основное действие каждого типа упражнения всегда находится в фиксированной нижней панели вместе с помощью.
- AC-3: Проверка недоступна и выглядит отключённой, пока ответ не заполнен; незаполненное сопоставление не показывает сообщение об ошибке и не записывается как попытка.
- AC-4: Успешная проверка продолжает существующий прогресс и переход; неправильный заполненный ответ можно исправить и отправить повторно.
- AC-5: Кнопка помощи использует узнаваемый стандартный векторный символ лампочки.
- AC-6: Debug APK собирается, устанавливается поверх приложения без очистки прогресса и визуально проверяется в текущем упражнении сопоставления.
- AC-7: `python3 tools/spec-lint.py` проходит после изменений WI, BOARD и канона.

## Dependencies

Текущая модель локального курса, Compose UI, `ProgressRepository` и запущенный эмулятор `emulator-5554`.

## Risks

Состояние выбора для разных типов ответа должно сохраняться только в рамках текущего упражнения и не менять существующее сохранение результатов; проверяется отправкой корректного и некорректного ответа в UI.

## Result

Реализовано 2026-09-25. Debug APK собран и установлен поверх приложения на `emulator-5554` без очистки данных. Локальное зеркало оставлено на упражнении 3/3 с выбранными соответствиями и включённой кнопкой проверки, чтобы пользователь мог продолжить аннотации. Кнопку не нажимал, чтобы не записывать тестовую попытку в сохранённый прогресс. Другой тип упражнения не открывал: общий нижний bar проверен по единой ветке `ExercisePanel`, которая выбирает действия для всех четырёх типов. Каталог не содержит `.git`, поэтому commit и статус Git недоступны.
