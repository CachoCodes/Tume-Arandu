# WI-048: Краткий ответ Tutor и проверка relay

Canon action: direct-edit

## Outcome

Tutor отвечает коротко, спокойно и без сырой разметки; Worker защищает ключи и сохраняет один результат при обрыве сети на этапах отправки, ожидания и получения.

## Scope

- In: исходная инструкция модели, ограничение и нормализация ответа, код-ревью Worker/секретов, проверки трёх сетевых переходов и существенные исправления в их контракте.
- Out: новый UI, смена AI-провайдера, публичная авторизация многих пользователей, локальная модель.

## Specs

- Governing: `spec://modules/android/PROP-010-android-demo-architecture#online`, `spec://modules/android/PROP-010-android-demo-architecture#privacy`.
- Affected: `spec://modules/tutor/FEAT-011-ai-tutor#online-provider` (draft).

## Acceptance

- AC-1: на короткую математическую задачу Worker возвращает короткий понятный ответ без Markdown и LaTeX, даже если провайдер прислал разметку.
- AC-2: API-ключ не попадает в код, APK, URL ответа или логи; запрос без личного токена отклоняется, размер тела ограничен и без `Content-Length`.
- AC-3: до POST, после принятия POST и при опросе статуса обрыв сети не теряет вопрос и не вызывает повторного обращения к провайдеру для того же ID.
- AC-4: тесты, структурный lint и живая проверка Worker проходят; нагрузка на Mac остаётся умеренной.

## Dependencies

Рабочий ключ уже загружен в Cloudflare secret; для тестов использовать фиктивные значения и один короткий живой вопрос.

## Risks

Жёсткое сокращение ответа может убрать нужное объяснение сложной задачи; краткий формат должен оставлять одно ключевое обоснование. Лексический фильтр математики остаётся приблизительным и не гарантирует смысловую классификацию каждого запроса.

## Result

2026-09-26. Worker 7702af5d-83e0-464f-884e-9c05fea66739 развёрнут. Краткий system prompt и серверная очистка ответа устраняют сырые `\\frac`, `\\circ`, Markdown и длинный текст. Исправлены три найденных дефекта: обход лимита тела без `Content-Length`, гонка одновременных повторов одного ID во время проверки месячной квоты и потеря таймера удаления/верного ответа при временной ошибке хранилища. Из ошибок провайдера убраны подробности, которые могли содержать чувствительные данные. Android-код не менялся, тяжёлая сборка/эмулятор не запускались.

REVIEW: в текущем дереве нет `.env`/`.dev.vars` и строк ключей; Wrangler показывает только имена двух secret bindings. Проверка DEX установленного APK не нашла Google key pattern или личный токен. Каталога `.git` здесь нет, поэтому история публичного репозитория не проверялась. Правило математической темы остаётся эвристикой; Worker ограничивает 100 новых вопросов за месяц, но не гарантирует денежный потолок $1 на стороне владельца общего API key. Повтор после неопределённой ошибки связи Worker→Google возможен только вручную с новым ID и может вызвать второй платный запрос. Python с default User-Agent получил Cloudflare 1010, Java/Dalvik-подобный клиент получил штатный ответ Worker.
