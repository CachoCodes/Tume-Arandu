# WI-037: Вторая визуальная итерация локальной карты

Canon action: none

## Outcome

Локальная карта с естественной тропой и обновлёнными элементами по пяти аннотациям.

## Scope

In: tools/map-preview/index.html; разворот треугольника и 60°, верхняя формула, контакт платформ с тропой, прозрачность dock, книга и ученик, верхние тема/XP/серия.
Out: Android, SDK, реальный прогресс, перенос макета.

## Specs

- Constraint: spec://modules/learning/FEAT-010-learning-demo#course-map — визуальная исходная точка; пользователь запросил независимый локальный макет.
- Related: WI-035, завершённая первая итерация.

## Acceptance

- AC-1: в браузере нижний треугольник развёрнут, подписаны 30°/60°/90°, верхний заменён sin 30° = ½.
- AC-2: дорожка на земле соединяет семь платформ; контактные тени и основания совпадают с их нижними гранями в общей изометрии.
- AC-3: dock прозрачнее, содержит линейные иконки книги/ученика; верх содержит тему слева, XP по центру, число дней и огонь справа, огонь серый без XP сегодня.
- AC-4: Android не изменён; макет доступен на localhost:8766, демонстрационные данные обозначены в оболочке.

## Dependencies

Существующий Python HTTP server, браузер Codex.

## Risks

Все числовые данные демонстрационные. Направление нижнего треугольника выбрано зеркально относительно первой итерации; камера остаётся прежней.

Готово 2026-09-26. `tools/map-preview/index.html`, localhost:8766, итерация 02. REVIEW: значения серии/XP образцы; ?today=0 предназначен для просмотра серого огня. Реальные экраны Android не подключены. Git отсутствует.
