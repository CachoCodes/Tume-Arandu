# WI-035: Локальный визуальный макет карты

Canon action: none

## Outcome

Отдельный локальный визуальный макет по четырём аннотациям пользователя, доступный сбоку в Codex.

## Scope

In: tools/map-preview; единая изометрия, стоящие треугольники без формул снизу, прямые грани платформ, стеклянная нижняя панель, демонстрационный streak.
Out: Android app, SDK, APK, прогресс, реальный учёт серии дней, перенос макета в приложение.

## Specs

- Constraint: spec://modules/learning/FEAT-010-learning-demo#course-map — текущая Android-карта используется как визуальная исходная точка; пользователь явно запросил отдельный макет без изменения канона приложения.

## Acceptance

- AC-1: localhost показывает отдельную карту с четырьмя визуальными изменениями в боковой панели Codex.
- AC-2: сетка, платформы и обе призмы используют единую изометрическую проекцию; формулы снизу отсутствуют.
- AC-3: файлы app не изменены, просмотр Android на 8765 сохранён; streak обозначен как демонстрационные данные в оболочке макета.

## Dependencies

Python stdlib HTTP server; браузер Codex.

## Risks

Макет визуальный: не связан с Android-навигацией и прогрессом. Перенос и реальный streak требуют отдельного запроса.

## Result

Готово 2026-09-26. Макет: `tools/map-preview/index.html`, http://127.0.0.1:8766/. Android-просмотр остался на 8765. REVIEW: серия дней и XP — образец, нижняя навигация не открывает реальные экраны. Переноса в Android нет. Git отсутствует в рабочей директории.
