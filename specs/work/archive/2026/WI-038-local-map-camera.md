# WI-038: Единое пространство локальной карты

Canon action: none

## Outcome

Третья локальная итерация с явной камерой, согласованными поверхностями и исправленными объектами по пяти аннотациям.

## Scope

In: tools/map-preview; камера и привязка платформ к сетке, нанесение номеров на поверхность, поворот треугольника по Z, объёмная формула, прозрачный dock и иконка профиля, горизонтальный streak.
Out: Android/SDK/APK, реальный прогресс, перенос визуального макета.

## Specs

- Constraint: spec://modules/learning/FEAT-010-learning-demo#course-map — исходный экран; пользователь явно разрешил только независимую визуальную итерацию.
- Related: WI-035, WI-037.

## Acceptance

- AC-1: камера явно задана: ортографическая, азимут 45°, elevation 35.26438968°; сетка/платформы/тропа/призмы/тени используют её; края платформ совпадают с границами клеток и остаются квадратами в мире.
- AC-2: нижний треугольник возвращён из зеркальной ориентации и повёрнут вокруг собственного Z к пользователю; 30°/60°/90° и стороны сохранены; формула имеет видимую экструзию в той же камере.
- AC-3: круговые фоны Tutor/Perfil убраны, dock просвечивает сетку, профиль простая улыбающаяся фигура; число серии слева от фиксированного огня, увеличение числа растёт влево, серое состояние сохраняется.
- AC-4: браузер показывает итерацию 03 на 8766; эта задача не меняет файлы app.

## Dependencies

Существующий Python server и SVG/JS без новых зависимостей.

## Risks

Ортографическая камера выбрана для сохранения изометрии; масштаб не уменьшается с удалением. Субъективное визуальное принятие пользователем остаётся следующей итерацией. Числа примерные.

## Result

Готово 2026-09-26. Макет на 8766, итерация 03. REVIEW: единая ортографическая камера, стандартная изометрия, объекты размещены в мировых координатах. Исходная проверка DOM показала совпадающие углы сетки/граней уже во второй итерации (30°/150°); новое изменение устраняет свободную фазу платформ относительно сетки и экранную типографику на гранях. Данные XP/серии демонстрационные. Git отсутствует. Снимок SHA-256 app за время работы изменился: Course.kt, CourseApp.kt, новый ArithmeticExpressionParser.kt; эта задача этих файлов не записывала и не откатывает внешние изменения.
