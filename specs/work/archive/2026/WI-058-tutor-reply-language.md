# WI-058: Язык ответа Tutor для смешанных вопросов

Canon action: direct-edit

## Outcome

Tutor отвечает на испанском на испанский математический вопрос, даже если в нём встречаются отдельные слова гуарани, и на гуарани на вопрос, заданный преимущественно на гуарани.

## Scope

- In: правило выбора языка в каноне и system prompt Worker, проверка промпта и два коротких живых вопроса.
- Out: Android UI, смена модели, отдельный классификатор языка, изменение частоты опроса.

## Specs

- Governing: `spec://modules/android/PROP-010-android-demo-architecture#online`.

## Acceptance

- AC-1: инструкция модели выбирает язык по явному пожеланию пользователя или по основному языку фразы, а не по одному-двум чужим словам.
- AC-2: живой испанский вопрос с отдельным словом гуарани получает испанский ответ; вопрос преимущественно на гуарани получает ответ на гуарани.
- AC-3: Worker tests и spec-lint проходят; чужие Android-файлы и API secrets не меняются.

## Dependencies

Действующий Worker и Gemini secret. Параллельные задачи в той же папке меняют профиль и уроки; наша правка ограничена Worker и его спецификацией.

## Risks

Один system prompt не даёт абсолютной гарантии языка на любой смешанной фразе. Проверка охватывает характерные случаи без нового классификатора, который сам мог бы ошибаться.

## Result

2026-09-26. В system prompt заменено правило, которое могло переводить испанский вопрос на гуарани: теперь явное пожелание языка имеет приоритет, иначе берётся основной язык фразы и её грамматика; одиночные заимствования и общие математические слова язык не переключают. Worker `cf81467f-1fb4-416e-9013-74f0ea05afbb` развёрнут. Android UI, частота опроса, модель и secrets не менялись. В общей папке нет `.git`, поэтому Git-состояние не доступно; параллельные задачи продолжают работу над Android отдельно.

REVIEW: system prompt повышает надёжность выбора языка, но не является абсолютной гарантией для любой смешанной формулировки. Отдельный классификатор намеренно не добавлялся, чтобы не вводить ложные переключения языка.
