# WI-045: Надёжная отправка вопросов онлайн Tutor

Canon action: direct-edit

## Outcome

Вопрос Tutor не теряется при плохой связи: приложение сохраняет незавершённый запрос, повторяет доставку с тем же ID и получает ответ через Cloudflare Worker без ключа Google в APK.

## Scope

- In: личный Cloudflare Worker, приём и проверка статуса запроса, ограниченный доступ, временное хранение до получения ответа, Android Online UI и восстановление незавершённого вопроса.
- Out: публичная многопользовательская авторизация, offline-модель, облачная история чата, фоновая доставка после закрытия приложения.

## Specs

- Governing: `spec://modules/android/PROP-010-android-demo-architecture#online`, `spec://modules/android/PROP-010-android-demo-architecture#privacy`.
- Affected: `spec://modules/tutor/FEAT-011-ai-tutor#root` (draft).

## Acceptance

- AC-1: повторная отправка одного ID после потерянного ответа не создаёт второй вопрос; результат можно получить отдельным запросом.
- AC-2: при недоступной сети вопрос и ID остаются на устройстве после перезапуска приложения, а при возврате в Tutor отправка продолжается.
- AC-3: ключ Google отсутствует в APK и репозитории; Worker требует отдельный секрет доступа и ограничивает длину вопроса, размер ответа и число новых вопросов в месяц.
- AC-4: ошибки авторизации и провайдера видны пользователю, а обычный курс продолжает работать без сети.
- AC-5: Worker и Android проходят локальные проверки; затронутый экран и соседнее состояние проверены в рамках ограниченного по ресурсам прогона.

## Dependencies

Рабочий ключ проверен прямым `generateContent` (`HTTP 200`) и повторно загружен как Cloudflare secret. Для публичного использования нужна отдельная авторизация пользователей; личный bearer token предназначен для одного устройства.

## Risks

При неопределённом результате запроса к Gemini возможна повторная тарификация; Worker не должен слепо повторять такой вызов. Короткоживущие серверные данные надо удалять по таймеру. Личный bearer token подходит только для доверенного личного использования, не для публичного APK. Лимит Worker не ограничивает чужое использование общего API key.

## Result

Готово 2026-09-26. Android и Worker работают с `gemini-3.8-flash` через `generateContent`. Первоначальные ошибки были вызваны некорректным вызовом `fetch` в Worker и старым секретом Cloudflare. Введённый пользователем ключ дал `HTTP 200` при прямом запросе к Google; после замены Cloudflare secret Worker вернул полноценный ответ и версия `c4b6ead9-acca-4f65-bb48-d963a448c644` опубликована. На эмуляторе вопрос пережил отсутствие сети и перезапуск, затем получил ответ с тем же ID. Локальный `.env` удалён после загрузки секрета. REVIEW: проверять качество Guaraní с преподавателем; личный токен не подходит для публичного многопользовательского APK. Git commit отсутствует: каталог проекта не содержит `.git`; рабочие файлы изменены локально.
