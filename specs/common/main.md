# О продукте

## Назначение

Android demo для изучения математики на Guaraní. Первый законченный сценарий — пройти короткий курс Trigonometry на одном устройстве без регистрации, выполнить упражнения, сохранить прогресс и при желании открыть AI Tutor.

## Пользователь и приоритет

Пользователь — человек, который изучает школьную/вводную тригонометрию и может читать Guaraní. Возраст, класс и локальный учебный стандарт пока не определены и должны быть проверены при наполнении курса.

Порядок приоритетов: APK запускается на Galaxy S24; офлайн-курс, теория, детерминированные задания, решения и локальный прогресс работают; затем online Tutor и proof-of-concept локального AI; затем streak/achievements/polish.

## Границы demo

Одно Android-приложение, один статический курс из 5–10 уроков, один пользователь на устройстве. Без аккаунтов, облачной синхронизации, CMS, backend, платежей, рейтингов и iOS-приложения. P0 learning flow и Android architecture приняты для реализации; AI Tutor остаётся draft из-за API credentials и model/device проверки.
